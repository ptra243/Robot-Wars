# Missing Tier Ladder Recommendations (T2/T3)

This proposes Tier 2 and Tier 3 values for card families currently missing one or both higher tiers.
Recommendations follow existing ladder patterns in this repo: keep identity stable, usually increase one primary output per tier, and avoid changing charge cost unless needed for pacing.

## Implementation notes

- Preserve existing `id`/`merge_to` chains: `_t1 -> _t2 -> _t3`.
- For cards that currently use `effects` arrays, prefer scaling those effect constants over adding new mechanics.
- For threshold-heavy junk cards, this proposal mixes two knobs: slightly lower thresholds and slightly stronger payouts at higher tiers.
- `neutral_capitalising_strike` t2/t3 assumes explicit effect params in JSON (for example: consume target Expose for bonus damage-per-stack) rather than text-only behavior.
- `neutral_shield_reinforcement` t2/t3 assumes adding flat `ShieldBlock` after `DoubleActorBlock` in `effects`.
