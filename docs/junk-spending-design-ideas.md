# Junk spending — reserved (not committed)

**Status:** **No global / rules-wide “junk spend” pillar is committed yet.** This file exists so linked docs have somewhere to point; ideas here (e.g. heal-on-spend, economy-wide hooks) **may never ship**.

**What still exists regardless:** Individual cards can use `**SpendJunk`** (or scripted spend steps) in card data — e.g. **Strip Mine**, **Scrap Derrick**, **Junk Recycle**, **Induction Pit**. That is **per-card** cost text, **not** the same as a **global** rule that rewards or punishes spending junk across the whole combat.

**Threshold pillar:** See **[junk-threshold-design-ideas.md](./junk-threshold-design-ideas.md)** — it does **not** depend on anything in this file.

If you drop the global-spend concept entirely, you can leave this stub as-is or delete it and remove links from other docs.
